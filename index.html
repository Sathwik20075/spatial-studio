🎧 Spatial Sound Studio

System-wide spatial audio. Start it once, close the window (it keeps running in the tray), then play YouTube, Spotify, games or movies as usual.

System-wide processing

Stopped
  • • Virtual cable installed
  • • System sound output is the cable
  • • Earbuds / headphones chosen in “Play to”
  • • Audio is reaching the app

Sound field (top view)

Drag the dot to place a 3D sound. Virtual-surround mode shows the virtual speakers around you.

Output type

Space & tone

Headphone modes use HRTF binaural rendering. Speaker modes use equal-power panning with mid/side widening, so there are no height cues. Bluetooth adds some latency, which doesn't affect spatial quality.
